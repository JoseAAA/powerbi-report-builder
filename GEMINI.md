# GEMINI.md

Lee **[AGENTS.md](AGENTS.md)** — es la guía canónica de este repo para agentes de IA
(reglas duras, tabla de scripts, mapa de `references/` y convenciones). Aplícala tal
cual en **Gemini CLI** y en **Antigravity**.

Resumen: framework para crear y auditar reportes de Power BI como proyecto **PBIP**
(TMDL + PBIR). El trabajo determinista lo hacen **scripts de Python (stdlib)** en
`scripts/`; el conocimiento citado vive en `references/`. No hay dependencias ni
nada específico de un proveedor.
