# Ejemplos acumulados (el skill aprende con el uso)

Aquí se guardan **ejemplos reales (anonimizados)** generados al usar el skill, para
no re-derivarlos en cada proyecto. No son plantillas a copiar tal cual: son
referencias de "cómo se ve uno bien hecho".

Qué va aquí (a medida que se usa):
- **Fichas KPI** buenas (`ficha-<indicador>.md`) — ver plantilla en `../ficha-kpi.md`.
- **Descubrimientos** bien levantados (`descubrimiento-<area>.md`).
- Cualquier artefacto de fase reutilizable como referencia.

Las **marcas** por empresa NO van aquí: van en `../marca/<empresa>.json` (activa)
o `../marca/ejemplos/` (muestras). Ver `../marca/README.md`.

Regla: anonimiza datos sensibles antes de guardar. Cada ejemplo que aporte un
criterio nuevo se anota en el `CHANGELOG.md`.
